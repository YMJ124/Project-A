# 问题 1：半机理与 A/F 共享学习筛选协议 v2

## 上一轮证据

v1 中，半机理特征增强的逐目标 Extra Trees 相对原始逐目标 Extra Trees 只使 `A_hops_citrus` 和 `F_hops_citrus` 的平均 RMSE 改善约 0.18% 和 0.39%，未达到 1% 发现线。纯机理 Ridge 和机理基线 + 残差 ET 均明显退化。

三个阈值激活度普遍饱和，但对 `A_hops_citrus` 仍保留中等排序信号，而 `F_hops_citrus` 的直接信号更弱。因此 v2 只验证一个新机制：让 A/F 两个同名描述词共享树分裂，检验较强的 Aroma 信号能否帮助 Flavour。

## 预声明设计

- 目标仍固定为 `A_hops_citrus` 和 `F_hops_citrus`。
- 外层 3 折、3 次重复，全新基础种子 `20471124`。
- 树参数继续固定为 250 棵树、`max_features=0.5`、`min_samples_leaf=5`。
- 半机理公式、阈值和基质交互与 v1 完全相同，不使用 v1 结果调参。

同折比较三个模型：

1. 原始全化学数据逐目标 ET。
2. 原始全化学数据 A/F 两输出共享 ET。
3. 原始全化学数据 + 半机理特征的 A/F 两输出共享 ET。

候选 3 必须分别相对候选 1 和 2 都满足：平均 RMSE 改善不低于 1%、至少 2/3 次胜出、Spearman 差中位数非负、等级不降，才能进入 7 个全新重复的确认。大提升仍定义为 RMSE 改善不低于 3% 或升到 A 级。
