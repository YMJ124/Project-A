# 问题 1：柑橘型酒花感官半机理筛选协议 v1

## 实验目的

检验“感官阈值启发的非线性化学特征 + 全化学数据残差学习”能否稳定优于同参数的原始 Extra Trees。

## 预声明目标

- `A_hops_citrus`
- `F_hops_citrus`

选择理由：两者都是当前 B 级且接近 A 级，同时有直接的酒花单营类醇协同文献支持。本轮不用结果从其他目标中事后挑选。

## 固定化学先验

附件 8 `Sensory thresholds` 表中的平均阈值（mg/L）：

- linalool: 0.027285
- citronellol: 0.0245
- geraniol: 0.0315

附件 1 的三个字段与附件 8 `Calibrated chemical dataset` 大多数样本直接对应，并与阈值表使用相同的 mg/L 量纲。个别样本在比赛附件 1 中已有不同的整理值，模型始终以正式附件 1 为输入，不从附件 8 回填数值。

由于真实感知阈值会随啤酒基质变化，本实验只称“阈值启发特征”，不声称计算了精确 OAV。

## 固定特征公式

1. 单化合物：`log(1 + c/t)` 与 Hill 激活度 `(c/t)/(1+c/t)`。
2. 协同与平衡：三项激活度的均值、最小值、最大值、标准差、几何均值、两两乘积和三项乘积。
3. 基质调节：pH、苦味度、酒精度在当前训练折内标准化，并与总负荷和协同强度做乘积。
4. 所有缺失填补、基质标准化、机理基线拟合和残差学习都只在当前外层训练折内进行。

## 四组同折对照

1. 原始全化学数据逐目标 Extra Trees。
2. 只用半机理特征的强正则 Ridge。
3. 原始全化学数据 + 半机理特征的逐目标 Extra Trees。
4. 半机理 Ridge 基线 + 全化学数据逐目标 Extra Trees 残差。残差由外层训练折内 3 折交叉预测形成。

四组都使用外层 3 折、3 个重复和同一组种子 `20461124`。Extra Trees 固定为 250 棵树、`max_features=0.5`、`min_samples_leaf=5`。

## 保护和采用规则

相对原始 Extra Trees，单目标只有同时满足以下条件才能进入全新种子确认：

- 平均 RMSE 改善不低于 1%；
- 至少 2/3 个重复 RMSE 更低；
- Spearman 差的中位数不低于 0；
- A/B/C 等级不下降。

将“大提升”预先定义为：平均 RMSE 改善不低于 3%，或把目标稳定提升到 A 级。发现阶段不直接改动当前冠军。
