# 问题二评估体系 v1

## 1. 定位与证据边界

本体系对照正式赛题 PDF、`AGENTS_2.md`、问题一冻结接口和附件实测结构建立。问题二的最终产物是“与样本外预测和感官变化稳定相关的关键化合物候选”，不是因果效应。

评估分为七道门：数据合同、问题一接口、网络稳定性、样本外解释、方法一致性、候选去冗余/化学审计、完整性与复现。任一阻断项未通过，正式 Top-3 状态必须为 `HOLD`。

## 2. 分层门槛

### G0 数据合同

- `1.csv`/`4.csv` 哈希与问题一冻结值完全一致。
- 250 样本、231 输入、30 主目标、73 个缺失值和 22 种风格均符合数据合同。
- 附件 2 必须能由附件 1 的成对完整样本 Spearman 重算，矩阵最大绝对差不高于 `1e-12`。
- 只按整数 `beer` 对齐，不使用 `beer_id`。

### G1 问题一接口

- 30/30 主目标都必须能追溯到冻结模型来源、A/B/C 等级和 OOF 指标。
- 每个解释折的重建预测与冻结 OOF 的最大绝对差必须不高于 `1e-9`。
- A 级可输出高可信候选，B 级最高只能是中等可信，C 级只能是探索性/证据不足。问题二不得上调问题一等级。

### G2 化学丰度相关网络

- 每个冻结外层训练折内重算 Spearman，使用 BH-FDR `<=0.05`，比较 `|rho|=0.30/0.40/0.50`。
- 正式运行每折做 200 次风格分层 bootstrap；边的符号、频率和区间分开保存。
- 将 `|rho|=0.40` 作为首选值的充分条件：训练折边集 Jaccard 中位数 `>=0.60`、边数 CV `<=0.15`、社区 ARI 中位数 `>=0.50`。这三个数值是根据 pilot 建立的后续确认目标，必须在全新重复上验证，不能反过来证明 pilot。
- 正负边分开报告；社区必须连通。网络中心性不能直接代替模型重要性。

### G3 样本外解释稳定性

- 主方法是外层验证折的风格内置换；小风格单元按预声明规则合并。无条件置换只作敏感性。
- 正式运行每特征、每折至少 100 次置换，主指标为 RMSE 增量，同时保存 R2/Spearman 损失。
- 单候选最低稳定线：Top-10 入选频率 `>=60%`，置换重要性为正的频率 `>=80%`，方向一致率 `>=70%`。
- 对样本数不少于 8 的风格检查方向反转；明显反转时降级或只报告风格条件结论。

### G4 方法一致性

- 必须同时报告验证折置换、TreeSHAP、简单训练折相关和相关组联合置换。
- 条件/无条件置换 Top-10 Jaccard 中位数目标 `>=0.50`。
- 置换与 TreeSHAP Top-10 Jaccard 必须报告；`>=0.30` 视为最低方法支持，`>=0.50` 为理想。低于最低线不一定否定模块，但禁止将单体写成唯一归因。
- 上述方法一致性门槛必须在正式 30 目标运行前锁定。

### G5 Top-3 去冗余与化学审计

- 高相关社区内无法区分的多个特征只保留一个稳定代表，其余作为“相关替代物”。
- 单特征置换低、社区联合置换高时，结论必须写为“共享信号模块”。
- 每个正式候选需有附件 6/8 的同源一致性审计，同时列出冲突；附件 6/8 不得用于主排名。
- 单位、变换和来源未核验时，不做 OAV/阈值结论。

### G6 完整性与决策

- 30 个主目标全部运行 7×3 冻结折；不得只报告表现好的目标。
- 每个 A/B 目标要么给出通过门槛的 Top-3/模块，要么明确写“证据不足”。C 级允许少报或不报。
- 最终候选中至少 80% 应在多数重复中置换重要性为正；Top-3 候选的 Top-10 入选频率中位数目标为 `>=60%`。
- 只有 G0-G6 所有阻断项通过才能冻结 `q2-freeze-v1`；否则保持 `HOLD`。

## 3. Pilot 与正式运行的区分

`q2_pilot_v1_1` 只用 1 次重复、3 个代表目标、20 次网络 bootstrap 和 10 次置换，用于验证工程与定义评估门。它不产生正式 `top3_candidates.csv`。由 pilot 设置的新网络/方法一致性门槛必须在新重复上确认，不得用同一 pilot 做确认证据。

## 4. 首版扩展实验和已采用优化

- `q2_explain_pilot_v1` 已对真实冠军流水线实现 TreeSHAP，并将缺失指示列归回原始特征；9 个目标—折的 SHAP 加和误差最大为 `7.77e-16`。
- 置换与 SHAP 的 Top-10 Jaccard 中位数为 `0.333`，通过 `0.30` 最低线，距 `0.50` 理想线还差 `0.167`。
- 风格方向反转率为 `6.09%`，通过 `10%` 上限，距 `5%` 理想线还差 `1.09` 个百分点。
- 网络优化在 repeat 0 锁定为：只用主阈值边中 bootstrap 出现频率 `>=0.90`、符号一致率 `>=0.90` 的边进行社区发现，同时保留完整 FDR 边表用于描述。
- 该机制在未见 repeat 1、每折 200 次 bootstrap 上通过全部预声明条件：社区 ARI `0.550 -> 0.647`，提高 `0.097`；边集 Jaccard `0.615`；中位边保留率 `50.14%`。决策为 `ADOPT`。
- 附件 6/8 同源审计覆盖 6/6 个 pilot 完整候选，附件 6 方向 6/6 一致，但附件 8 的 GBM MDI/SHAP sheet 未标识感官目标，因此不进入排名。
- 稳定社区去冗余后，`A_hops_all` 的 `ethyl_octanoate`/`ethanol..v.v.` 为一个模块，`ethyl_decanoate` 为另一模块；`F_esters_isoaa` 的 `kcalperc`/`isopentyl_acetate` 为一个模块，`protein.g.L.` 为另一模块。这些仅是 pilot 模块，不是正式 Top-3。

当前综合评估为 13 `PASS` + 7 `PARTIAL`，正式状态仍为 `HOLD`。

## 5. 模块归因优化及独立确认

- 首个机制为稳定社区内汇总绝对 SHAP，与社区联合置换的 Top-10 比较。在未见 repeat 2 上，Jaccard 从 0.333 提高到 0.429，9 个目标—折中 6 个改善；但未达到预声明的 0.50 绝对线和 0.10 改善线，决策 `REJECT`。
- 失败诊断发现每折约 47 个稳定模块，Top-10 覆盖约 21% 的模块，与最终 Top-3 候选任务不匹配。因此建立新版本：G4 仍保留原 Top-10 报告，只将模块 Top-5 用作 Top-3 前的候选池。
- Top-5 版本在未见 repeat 3 上确认：单体 Jaccard=0.250，模块 Jaccard=0.667，中位改善=0.238，8/9 个目标—折改善，两个 A/B 目标中较低的中位模块 Jaccard=0.429。四项预声明条件全部通过，决策 `ADOPT`。
- 该机制只改变归因与去冗余的报告单位，不改变问题一预测，不会提升 C 级目标的可信等级。

## 6. 全来源实现审计与七重复网络确认

- 30/30 主目标已在冻结 repeat 4 的三个外层折精确重建，共 90/90 个
  目标—折通过，最大绝对误差为 0。这证明全部冻结冠军架构均已进入问题二，
  但不替代 7×3 的正式解释运行。
- 九类可执行来源分别通过 TreeSHAP 审计，最大加和误差为 `1.67e-15`；
  SelectK 专家在未入选特征上的贡献已显式回填为零。
- 30 目标的一折置换、TreeSHAP 和相关组联合置换工程 smoke 均通过；
  smoke 只验证端到端兼容性，不进入正式 Top-3 或稳定性计数。
- 200-bootstrap 网络现已覆盖全部 repeats 0--6。稳定边筛选在 5/7 次通过
  相对改善线，独立 repeats 1--6 为 4/6；repeats 4/5 分别下降
  `0.0067/0.0084`。但七个重复的绝对稳定社区 ARI 均不低于 0.50，
  边 Jaccard 和保留率也均通过。故最终报告必须同时展示稳定边和未筛边
  网络，不得将该机制描述为每个重复都改善。
