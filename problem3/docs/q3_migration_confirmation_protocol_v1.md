# Pils/Lager -> Tripel 重复外层迁移确认协议 v1

## 证据边界

- 使用全新、在锁定本协议时尚未查看结果的 repeats 25--31，每次 3 折。
- 每个外折中，中位数填补、缩放、PCA、CORAL、Sinkhorn、Tripel 中心、风格分类器和冻结 Q1 预测器只在外层训练行拟合。
- 外层验证折中的 Pils/Lager 只作待迁移源样本，不参与当折任何拟合或选择。
- 公开 `test data` 不参与本轮选择、停止或验收；它已降级为发现性证据。

## 固定候选和选择

不调参地比较 PCA 质心平移、收缩 CORAL、正则 Sinkhorn 重心映射和 3/6/12 个 Q2 模块的反事实。扫描固定预算 0.25/0.5/0.75/1.0。

参考线“原样不改”和“最近真实 Tripel”不可入选。入选候选必须：

1. 通过数值、物理范围、派生字段和缺陷约束；
2. 不是真实训练样本的精确复制；
3. 不落入训练折 q05 危险近邻区；
4. Tripel 风格概率提高；
5. 到训练折 Tripel 化学中心的距离缩短。

在同时满足上述条件的 Pareto 候选中，保留至少最佳风格改善 50% 的点，然后选标准化 L1 代价最小者。

## 预注册通过线

硬门必须全部满足：

- 7 次重复的 11 个源样本均在其外层验证折中被迁移，预期 77/77 有选定结果。
- 选定结果的数值、范围、派生字段和四类化学缺陷全部通过。
- 精确复制与危险近邻必须为 0。

稳定改善门槛：

- 风格概率改善行比例 >=80%，至少 5/7 个重复的平均改善 >0，至少 9/11 个源样本的跨重复中位改善 >0。
- Tripel 化学距离改善使用相同的 80%、5/7 和 9/11 线。
- 冻结 Q1 24 个 A/B 目标的目标中心距离改善行比例 >=70%，至少 5/7 个重复的平均改善 >0，至少 8/11 个源样本的跨重复中位改善 >0。

标准化 L1/L2、改动字段数和 Q2 模块数均完整报告，但本轮不为它们事后设通过线。若正式确认通过，它们将用于下一轮稀疏迁移的预注册基线。

## 最小产物

- 新折分配及 manifest；
- 逐折全候选、Pareto 表和选定化学谱；
- 逐源样本的风格、化学、L1/L2、字段/模块和缺陷指标；
- 冻结 Q1 迁移前后感官距离和逐目标预测；
- 按重复、源样本和方法的汇总；
- 选择审计、运行 manifest 和决策文档。
