当前不限方法的 migration v2 已在全新 repeats 32--38、7x3 风格平衡外层折上通过所有预注册条件，状态为 `MIGRATION_CONFIRMATION_PASSED_WITH_Q1_LIMITATIONS`。

## v1 范围门诊断

v1 repeats 25--31 严格拒绝：只选出 70/77。未选的 7 行都是因验证源样本本身已有 1--4 个字段超出该外折训练 min/max，而迁移未进一步恶化这些字段。v2 在查看新折前锁定为“训练范围与配对源值包络，禁止进一步向外”。v1 不翻案，v2 使用全新证据确认。

## 稀疏迁移结论

只允许 3/6/12 个 Q2 模块反事实入选的稀疏方案在 repeats 32--38 发现筛选中表现良好，因此进入全新 repeats 39--45 与同折不限方法基线比较。

稀疏方案自身仍通过绝对迁移门槛：77/77 覆盖、风格和化学改善均为 77/77、A/B 感官改善 74/77。但成对替换门槛的结果为 `SPARSE_MIGRATION_REJECTED`：

| 指标 | 稀疏/基线 | 预注册线 | 结果 |
|---|---:|---:|---|
| 风格增益保留 | 64.10% | >=75% | 失败 |
| 化学改善保留 | 104.04% | >=75% | 通过 |
| A/B 感官平均改善保留 | 91.08% | >=90% | 通过 |
| 改动字段比 | 57.75% | <=80% | 通过 |
| 改动模块比 | 46.45% | <=80% | 通过 |
| 标准化 L1/L2 比 | 66.94% / 82.58% | <=100% | 通过 |
| 同时减少字段与模块的重复 | 7/7 | >=4/7 | 通过 |

稀疏方案将平均改动从 92.0 字段/20.1 模块降为 53.1 字段/9.35 模块，但风格增益损失超过锁定线。因此它只作“更低成本的保守备选”，不替换正式 migration v2。不将 75% 事后改为 64%。

## 当前采用规则

- 正式默认：不限方法的 migration v2，并报告 Pareto 代价。
- 实物试验成本严格受限时：可附加展示模块限定备选，但必须标记风格增益保留线失败。
- 不使用已查看的外部评论数据选择两者。
