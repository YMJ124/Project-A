# 问题三评估框架 v1

## 验证边界

问题三继承问题一的 7 重复、3 折风格平衡划分。每个外折内只使用训练样本拟合填补、缩放、降维、风格条件分布和风格识别器。验证样本不参与生成器选参或约束边界拟合。

## 条件生成的五类主评估

1. **边际分布**：目标风格中逐特征 Wasserstein 距离、中位数/分位数偏差和训练范围越界率。
2. **联合结构**：目标风格 Spearman 矩阵差、问题二稳定边的符号/强度保留和社区内共变。
3. **风格一致性**：仅在训练折拟合的风格分类器对生成样本的目标风格概率，并与真实留出样本比较。
4. **多样性与记忆**：生成样本成对距离、到最近训练样本的距离和近邻复制率；不把直接抽取训练行视为新样本。
5. **缺陷与物理约束**：DMS、Diacetyl、4VG 的超阈值违反和 trans-2-nonenal 的相对恶化作为化学约束；`X4vg` 可作经 OOF 验证的补充感官审计；`dms`、`diacetyl`、`t2n`、`stale_hops` 的感官预测均为 C 级，只能探索性报告，不能作为硬性通过条件。

## 跨风格迁移

Pils/Lager -> Tripel 的每个样本同时报告：

- 目标风格概率变化和是否跨过预声明的风格判定线；
- 按训练折尺度标准化的 L1/L2 改动；
- 实际改变的化学字段数与问题二候选模块覆盖；
- 四个化学缺陷约束、一个已验证的 4VG 感官审计和 `stale_hops` 探索性监控的逐项状态；
- 问题一标准化感官画像变化及其目标等级限制。

## 首轮基线比较

首轮只比较可解释的小样本基线：风格经验重采样、加噪近邻采样、收缩高斯和 PCA 潜空间风格采样。评估系统通过后再决定是否引入深度生成模型。
