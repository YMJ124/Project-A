# Q3 当前最优工程方案与目标差距 v1

## 1. 定案

在允许少量结构损失、要求综合净提升的前提下，当前最优方案锁定为：

> 半收缩 SKEPTIC 生成分布（50% Ledoit--Wolf / 50% Spearman-SKEPTIC，prior=5）
> + q05 最小训练距离拒绝
> + 固定秩相关正态分数分层抽样与父样本秩重排。

分层抽样只改变有限批次的采样设计，不改变折内拟合分布、经验边际、化学约束或评估器。

该方案是当前“综合效果最优的工程/Pareto 方案”，不是严格统计意义上的正式生成冠军。正式状态仍为
`HOLD_NO_GENERATOR_CHAMPION`，因为第二轮独立化学确认中 Q2 边丢失率 PASS 为 33/63，父方案为
36/63，而预注册上限是最多减少 2/63。

## 3. 理想 100% 覆盖参考

这不是额外硬门槛，只用于说明距离理想状态还有多少：总体真实参考距离 PASS 为 77.51%，Wasserstein 核心为 93.65%，Spearman 结构为 82.54%，Q2 边强度为 73.02%，Q2 边丢失率为 52.38%。小样本风格的真实—真实参考线本身存在波动，不能把这些缺口直接解释成模型完全不可用。

## 4. 当前限制

1. 严格预注册状态仍是 `HOLD_NO_GENERATOR_CHAMPION`，不能写成 `READY` 或正式冠军。
2. Q2 边丢失率有 3/63 个单元跨过最低线，且三个跨线单元均为 Kriek；连续均值没有恶化。
3. Q1 仍为 `HOLD`；6 个 C 级感官目标只能探索性报告，`stale_hops` 等缺陷感官不能作为可靠控制证据。
4. 外部 `test data` 仍未评分，Pils/Lager → Tripel 迁移尚未开始。

## 5. 暂不执行的后续优化方向

本轮不再训练、调参或启动下一阶段。若未来重新优化，必须使用全新外层随机种子并提前注册：

1. 优先检查 Kriek 小样本格的真实—真实参考线宽度、Q2 边有效样本数和近线阈值敏感性；连续 Q2 误差应与 PASS 计数同时报告。
2. 保持当前 SKEPTIC 分布与分层机制不变，只验证一个降低 Q2 边界跨线率的折内采样稳定化机制；不得把本轮 2/63 上限事后改为 3/63。
3. 若新机制不能在未见折上同时保护感官和结构，则冻结当前方案作为工程版本，不继续追逐单项计数。
