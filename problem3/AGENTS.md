# MathorCup 2026 赛道 A：问题 3 工作约定

本文件是问题三工作区的持久指引。开始生成建模、风格迁移或缺陷约束实验前，必须先阅读根目录 `AGENTS.md`、`AGENTS_2.md`、`AGENTS_3.md`、`CONTEXT.md`以及问题一冻结说明。当前状态、公开 `test data` 使用边界和正式实施顺序以根目录 `AGENTS_3.md` 为准。

## 1. 任务边界

- 以 `tasting_category_fine` 为条件，生成 Tripel、Kriek、Lambic 等风格的合理化学谱。
- 完成 Pils/Lager -> Tripel 的跨风格迁移，同时最小化原始样本改动。
- 使用问题一的真实冻结流水线计算感官画像，不得为问题三重新挑选更有利的感官模型。
- 使用问题二的稳定化学网络和候选模块作为合理性与可执行干预证据，不将关联解释为因果。

## 2. 数据合同

- 化学谱：附件 1，250 个样本、231 个化学/理化字段。
- 感官接口：附件 4 的 50 个标准化连续目标；其中 30 个 Aroma/Flavour 目标继承问题一冻结冠军，20 个补充目标在没有样本外证据前不得宣称为已验收预测。
- 主键只使用整数 `beer`；禁止用低精度 `beer_id` 跨表连接。
- 风格标签只用于条件生成、分层验证和风格识别评估，不允许泄漏目标测试样本。

## 3. 缺陷约束

- `DMS`、`X2.3.butanedione`、`X4VG`、`X.E..2.nonenal` 是化学字段；`stale_hops` 是感官目标，不得当作化学浓度。
- 所有阈值比较必须在附件 8 校准量纲上进行。`DMS` 和 `X4VG` 在附件 1 中为 log10 尺度；逆变换和检出限截断必须显式记录。
- trans-2-nonenal 无可用的本地阈值，预设使用“迁移后不高于迁移前”的相对约束，不得凭空填阈值。
- `stale_hops` 只能用专用的、有样本外验证的补充感官模型约束；该接口完成前不得宣称五类缺陷已全部受控。

## 4. 建模顺序

1. 稳健分位数/近邻采样基线。
2. 全局降维 + 带收缩的风格条件分布。
3. Gaussian copula 或其他小样本表格生成基线。
4. 只有在相同外层验证中证明改善后，才引入 CVAE/CTGAN/TVAE/扩散模型。

深度模型不是默认主方案。任何生成方案都必须与经验分布和近邻基线比较。

## 5. 验证和泄漏边界

- 模型选择、预处理、降维、条件分布、风格分类器与约束阈值必须只在当前训练折内拟合。
- 主评估至少包括：边际分布、相关/网络结构、风格可识别性、多样性、最近邻记忆风险、物理范围违反率和缺陷不恶化率。
- 跨风格迁移同时报告风格改善、标准化 L1/L2 改动、实际改变字段数和缺陷约束违反。
- 任何训练样本的近邻复制、直接返回原样本或在全数据上选参都不得解释为生成能力。
